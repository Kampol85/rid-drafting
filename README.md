# RID drafting tracker

ระบบติดตามงานเขียนแบบ กรมชลประทาน — รับข้อมูล, ปริมาณแบบ, ใบเสนอราคา, ตารางงาน, เบิกจ่าย

เว็บ: https://kampol85.github.io/rid-drafting/

ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้ (localStorage) — ไฟล์แนบ (KMZ, ใบเสนอราคา ฯลฯ) เก็บใน IndexedDB ของเบราว์เซอร์ — ใช้ปุ่ม ส่งออก/นำเข้าข้อมูล เพื่อสำรองหรือย้ายเครื่อง (รวมไฟล์แนบ)
